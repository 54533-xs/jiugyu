# 悬浮聊天与记忆优化

本轮工作范围：

- 悬浮聊天窗口的输入区、功能面板与软键盘适配。
- 主号与小号按独立身份保存聊天和记忆，模型只接收昵称。
- 小号编辑和删除，绑定关系仅用于收纳。
- 记忆页面统一搜索标签、内容、昵称和会话。
- 角色记忆列表分段加载。
- 聊天发送与重新生成的界面响应和上下文处理优化。

实现说明：

- 真实会话按账号独立保存；角色短期记忆汇总所有相关会话，以昵称区分联系人，不发送主号/小号标签。
- 新消息保存发送时的昵称，旧消息根据所属会话解析。身份编辑不会修改历史消息，小号删除保留历史资料供记忆读取。
- 记忆首页先显示角色，后台只补充数据库计数；进入详情才分批组装时间线。搜索覆盖全部已加载记录，最多渲染最近 2000 条匹配结果。
- 消息读取按会话建立位置索引，避免重复扫描其他会话。私聊不再重复组装当前会话；群聊复用已组装的角色时间线。
- 点击生成后先绘制状态，再处理上下文；长聊天记录组装按批次让出主线程。
- 悬浮聊天采用标题、可伸缩消息区域、底部输入区的布局，扩展输入区域可在窗口内滚动。

验证：类型检查、生产构建、385 个现有提示词场景、SDK/推送一致性检查、身份与索引专项回归。

测试重点：手机软键盘展开与功能面板；大数据账号发送/重试响应；小号改名、删除和切换后的记忆昵称。实际 API 等待时间仍由接口决定。

PR 保持开放，供真机测试。

## 生图结果下载与重复计费修复

- 服务端模式直接请求服务端或已配置的 Worker，移除先浏览器直连再回退的生成 POST，避免图片下载失败触发第二次生图。
- 图片 URL 在浏览器下载失败时交给独立下载接口，只取回原图。下载接口不接收 API Key，不调用生成端点，并限制公网地址、重定向和下载大小。
- 保存已生成但尚未下载成功的图片地址；同一配置、提示词和参考图重试或刷新后继续取原图。请求特征只保存 SHA-256，不保存明文密钥或参考图。
- 服务端已生成但下载失败时返回完成状态及图片地址，客户端保留并恢复结果；连接中断且无法确认完成状态时提示先检查 API 后台。
- 新增模拟回归：`node scripts/check-image-result-recovery.cjs`。验证过程中不调用真实生图接口。

旧版本未保留下来的失败图片地址无法自动补回，应从 API 后台下载已有图片。新代码需部署后才生效。

## 中文思考展示开关

聊天信息中新增“启用内置中文思考提示词”，按会话保存，默认关闭。开启后仅在线上私聊/群聊原请求中附加中文角色独白规则，使用当前身份昵称，不署名，不指定额外风格。独白是面向读者的角色创作文本，不代表模型真实内部推理。

沿用当前预设的思考标签及既有展示区域，请求内临时启用标签提取，不改写共享预设。流式预览隐藏未闭合的独白标签，正式聊天正文独立展示。关闭后恢复原有处理，历史消息保持不变；线下及自定义纯文本/结构化任务不附加本规则。

专项验证：`node scripts/check-chinese-thinking-prompt.cjs`，覆盖请求注入、默认关闭、即时读取会话配置、小号昵称、自定义标签、流式隔离及私聊群聊；不调用真实 API。
